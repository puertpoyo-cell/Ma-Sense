# COMPLIANCE — 의료 경계·문구·심사

이 문서는 사람이 읽고 결정하는 문서입니다. Claude Code는 이 문서의 금지선을 넘는 요청을 받으면 거절하고 여기를 가리킵니다.

## 1. 포지션 선언

마선생은 **의료기기가 아닌 자가 기록·알림 보조 앱**입니다. 근거와 경계:

| 구분 | 내용 | 마선생의 선택 |
|---|---|---|
| 의료기기 아님 | 복용 시간 알림, 자가 관리 보조는 의료기기 해당 없음 (식약처 가이드라인, 메디칼타임즈 보도) | 기록·알림·정리까지만 |
| 전문가용 디지털의료기기 | 투여량 판단 소프트웨어는 전문가용 (식약처 2026-09-30 가이드라인) | 용량·증량 관련 기능 전면 배제 |
| 전문의약품 광고 | 전문의약품은 대중 광고 제한, 상표 사용 시 광고·상표권 소지 | 앱 이름·화면·스토어 문구에 상표 미사용 |
| 오남용 맥락 | 정상 체중·미성년자 처방 보도 | 만 19세 이상 고지, 감량 부추기는 장치 배제 |

출처는 아이디에이션 문서(2026-10-13) 링크 참조. 배포 전 최신 가이드라인 재확인 필요.

## 2. 금지선 (코드·문구·화면 공통)

### 2.1 절대 금지
1. 용량 수치 해석, 증량·감량 시점 제안, "다음 단계", "증량 가능" 등 표현
2. 특정 약물명·상표명 (앱 이름, UI, 알림, 코드 식별자, 스토어 설명, 스크린샷)
3. 칼로리 목표, 목표 체중 입력, "목표까지 n kg"
4. 랭킹·경쟁·공유 비교, 스트릭·배지·게임 보상
5. 커뮤니티·사용자 간 메시지·게시판
6. 끼니 거르기·급감량을 긍정하는 문구·애니메이션·아이콘
7. 증상에 대한 대처법 제시 ("구역이 있으면 ~하세요") — 의료 조언

### 2.2 허용하되 조건부
| 항목 | 조건 |
|---|---|
| 단백질 권고 범위 1.2~1.6 g/kg | 출처 명시(`protein.source`: 2025 ACLM·ASN·OMA·TOS 공동 권고문, 감량 중 목표로 제안된 범위) + "개인 상황은 의사와 상의" 고정 문구 + 사용자/의료진이 목표를 입력하는 구조 |
| 근력운동 예시 루틴 | "일반 건강관리 정보" 표기, 개인 맞춤 아님, 강도 조절은 사용자 |
| 감량 속도 안내 | 일반 권장 범위(주 0.5~1 kg, CDC) 출처 명시, "일반적인 권장일 뿐 … 의사와 상의하세요"로 끝남, 느린 경우 안내 없음 |
| "작게 자주" 식품 제안 | 식품 종류만, 양·칼로리 없음 |
| 사용자 메모 `doseLabel` | 자유 텍스트. 앱은 파싱·해석·표시 변환하지 않음 |

## 3. 문구 가이드

### 3.1 톤
- 담담한 기록 선생. 모든 완료는 "기록했습니다."
- 느낌표·이모지 없음
- 판단어 금지: 좋음, 나쁨, 잘함, 부족, 충분, 성공, 실패, 달성(단백질 목표 "채웠습니다"만 허용)

### 3.2 고정 문구 (키 → 한국어)

| 키 | 문구 |
|---|---|
| `role.notice` | 처방은 의사가, 기록은 마선생이. 마선생은 투약과 생활을 기록하고 정리할 뿐, 의학적 조언이나 판단을 하지 않습니다. |
| `age.notice` | 이 앱은 의사의 처방을 받은 만 19세 이상 성인을 위한 기록 도구입니다. |
| `symptom.severe` | 증상이 심하면 의사와 상담하세요. |
| `protein.guide` | 일반적인 권고 범위는 체중 1 kg당 1.2~1.6 g입니다. 신장 질환 등 개인 상황은 의사와 상의하세요. |
| `pace.notice` | 최근 2주 체중이 일반 권장 속도(주 0.5~1 kg)보다 빠르게 줄었습니다. 일반적인 권장일 뿐 사람마다 다를 수 있으니 의사와 상의하세요. |
| `pace.source` | 출처: 미국 질병통제예방센터(CDC) 체중 감량 안내, 주 1~2파운드(약 0.5~1 kg) |
| `report.disclaimer` | 이 리포트는 사용자가 직접 기록한 내용을 정리한 것이며 의학적 판단이나 권고를 포함하지 않습니다. 처방과 치료 결정은 담당 의사에게 있습니다. |
| `exercise.general` | 아래 예시는 일반 건강관리 정보이며 개인 맞춤 운동 처방이 아닙니다. 몸 상태에 맞게 조절하세요. |
| `data.local` | 모든 기록은 이 기기에만 저장되며 외부로 전송되지 않습니다. |

### 3.3 알림 문구
- 약 이름·용량·"주사" 단어 없이: "오늘은 투약일입니다", "아직 기록이 없습니다"
- 잠금화면에 노출되므로 민감 정보 최소화

## 4. App Store 심사 대비

### 4.1 연령 등급
- 17+ : "빈번한/강한 의료/치료 정보"는 아님 → "드문/경미한 의료/치료 정보" + 자체 만 19세 고지. 최종은 심사 시 판단

### 4.2 Health 가이드라인 (App Review 5.1.3 등)
- HealthKit 데이터를 광고·마케팅에 사용하지 않음 (해당 없음, 분석 SDK 없음)
- HealthKit 데이터를 iCloud 외 제3자 저장 안 함 (서버 없음)
- 개인정보 처리방침 URL 필수 — "데이터는 기기에만, 수집 없음" 명시
- `NSHealthShareUsageDescription` (`Masense/Resources/InfoPlist.xcstrings`): "Apple 건강 앱의 체중, 제지방량, 운동 기록을 읽어 앱의 기록과 진료 전 리포트에 함께 보여 줍니다. 건강 앱에는 아무것도 쓰지 않으며, 데이터는 이 기기에만 저장합니다." — 읽는 항목, 쓰는 곳, 쓰기 없음, 기기 저장을 밝힌다

### 4.3 의료 앱 관련
- 앱이 진단·치료를 하지 않음을 설명에 명시
- 스토어 설명에 특정 약물명 사용 금지. "주 1회 주사 치료를 받는 분의 기록 도구"처럼 일반 표현

### 4.4 결제
- 비소모성 1종, 복원 버튼 필수
- 유료 기능(PDF 내보내기)이 건강 안전과 무관함을 확인 — 기록·알림은 전부 무료

### 4.5 스토어 설명 초안 방향
```
처방은 의사가, 기록은 마선생이.
주 1회 주사 치료를 받고 계신가요? 마선생은 투약 날짜와 부위, 투약 후 컨디션, 체중을 담담하게 기록하고, 진료 전 한 장의 리포트로 정리합니다.
- 투약 알림과 다음 투약까지 카운트다운
- 주사 부위 기록
- 투약 후 24·48시간 컨디션 체크
- Apple Health 체중 연동
- 단백질과 근력운동 기록으로 감량의 질 확인
- 진료 전 리포트 PDF
마선생은 의학적 조언을 하지 않습니다. 모든 기록은 기기에만 저장됩니다.
```

`scripts/compliance_check.py`가 GitHub Actions에서 푸시마다 돈다 (job "금지선 점검"). 직접 돌리려면 저장소 루트에서 `python3 scripts/compliance_check.py`.

| 점검 | 대상 |
|---|---|
| 약물명·상표명·성분명 (2.1-2) | 코드·테스트·문자열·docs·CLAUDE.md 전부 |
