# REPORT_SPEC — 진료 전 리포트 PDF

마선생의 시그니처 기능. 의사가 **3초 안에** 투약 이행·부작용·체중 추이를 읽어야 합니다. 건축 도면처럼 그리드에 정렬합니다.

## 형식

- A4 세로 1장 (210×297mm). 넘치면 폰트를 줄이지 않고 **기간을 줄이라고 안내**
- 여백 16mm, 12컬럼 그리드, 거터 4mm
- 인쇄 전제: 흰 배경, 검정·회색 중심. 테마는 강조색 1가지만 바꿈 (구매 기능)
- 폰트: Pretendard 또는 시스템(Apple SD Gothic Neo). 숫자는 tabular figures
- 렌더: SwiftUI 뷰 → `ImageRenderer` → PDFKit. 미리보기 화면과 동일 뷰 재사용

### A. 헤더
- 좌: "투약 기록 리포트" (제목), 아래 기간 "2026.09.02 – 2026.10.27 (8주)"
- 우: "마선생 Masense" 워드마크 소형, 생성일
- 환자 이름 없음. 사용자가 직접 보여 주는 문서이므로 식별 정보를 넣지 않는다

### B. 요약 4칸 (가로 4등분)
| 칸 | 값 | 보조 |
|---|---|---|
| 투약 | "8회 / 예정 8회" | 누락 n회 (0이면 "누락 없음"), 기간 내 처방 전환 n회 |
| 체중 | "-3.2 kg" (기간 시작 대비) | 시작 → 현재 kg |
| 컨디션 체크 | "14 / 16회 응답" | |
| 남은 회차 | "2회" | 소진 예상일 |

수치만. 화살표·색상 판단 없음. 체중 변화는 부호 그대로 (+도 그대로).

### C. 투약 타임라인
- 가로 축: 마디(주). 최대 12칸
- 각 칸: 날짜(M/d), 부위 약어(복좌상·허우 등), 회차
- 누락 마디: 점선 테두리 + "기록 없음"
- 예정일과 실제일이 2일 이상 차이: 실제 날짜 옆 소형 "(+2d)"
- 부위 로테이션은 아이콘 없이 텍스트. 의사가 "같은 부위 연속" 여부를 한눈에 보게
- **처방 전환 표시**: `prescriptionTimeline`의 각 마커를 해당 마디 칸 왼쪽에 세로 실선 1px로 긋고, 위에 소형 라벨로 `doseLabel` 텍스트(비어 있으면 "처방 변경")와 날짜. 기간 시작 전에 시작된 처방(`isFirstInPeriod`)은 첫 칸 왼쪽에 같은 방식으로 "기간 시작 시 처방: {label}". 앱은 라벨을 해석하지 않으며, 의사가 "언제 단계가 바뀌었는지"를 읽는 용도

### D. 체중 추이
- 주 평균 라인 (R7), 샘플 없는 주는 끊김
- y축: 최소·최대 2개 라벨만. x축: 주 시작일
- 투약일에 작은 세로 눈금
- HealthKit 출처면 "Apple Health" 소형 표기, 수동 입력 포함이면 "일부 수동 입력"

### E. 부작용 빈도
- 표: 증상 | 발생 횟수 | 최대 강도 | 주로 나타난 시점(24h/48h)
- 발생 0인 증상은 숨김. 하나도 없으면 "기록된 증상 없음"
- 심각도 3이 있던 증상은 굵게 (색 아님)
- 식욕: "줄었음 n회, 많이 줄었음 n회"

### F. 감량의 질 (M2, 데이터 있을 때만)
- 3칸: 단백질 채운 날 "n / 기간 일수" (목표 입력 시) 또는 "평균 n g/일" / 근력운동 "n회" / 골격근량 "시작 → 현재 kg" (입력 시)
- 목표 미입력이면 단백질 칸은 "기록 n일, 평균 n g"
- 이 섹션에 "충분", "부족" 같은 평가어 없음

### G. 메모 발췌
- Dose.note, ConditionCheck.note 중 비어 있지 않은 것 최근 5개, 날짜와 함께 1줄씩 (60자 자름)
- 없으면 섹션 생략

### H. 푸터
- 좌: "이 리포트는 사용자가 직접 기록한 내용을 정리한 것이며 의학적 판단이나 권고를 포함하지 않습니다. 처방과 치료 결정은 담당 의사에게 있습니다."
- 우: "생성 2026.10.27 14:02 · Masense 1.0"

## 데이터 → 렌더 계약

```swift
struct ClinicReport {            // Rules/ReportBuilder.swift 가 생성, 뷰는 이것만 받음
    let period: DateInterval
    let summary: Summary           // B
    let cycles: [CycleCell]        // C
    let prescriptionMarkers: [PrescriptionMarker]  // C 세로선
    let weight: [WeekPoint]        // D
    let symptoms: [SymptomRow]     // E
    let quality: QualitySection?   // F, nil이면 섹션 생략
    let notes: [NoteLine]          // G
    let generatedAt: Date
    let appVersion: String
}
```

- `ReportBuilder.build(...)`는 순수 함수. 테스트에서 고정 데이터로 스냅샷 비교
- 뷰는 계산하지 않는다. 숫자 포맷(소수 1자리, 부호)도 Builder에서
