# 개인정보 처리방침 — 마선생 Masense (초안)

> 게시 주소: https://masense-privacy.vercel.app/ (Vercel, `docs/privacy/index.html`). 앱 설정 > 정보의 링크는 `Masense/App/AppConfig.swift`의 `privacyPolicyURL`.

시행일: 2026년 10월 30일

마선생(이하 "앱")은 사용자의 기록을 기기 안에서만 다룹니다. 이 문서는 앱이 어떤 정보를 어디에 두고 어떻게 지우는지 설명합니다.

## 1. 수집하는 개인정보

앱은 개인정보를 수집하지 않습니다. 운영자 서버가 없고, 회원가입·로그인이 없으며, 분석·광고 도구(SDK)를 넣지 않았습니다.

## 2. 기기 안에 저장하는 정보

사용자가 직접 입력하거나 Apple 건강 앱에서 읽어 온 아래 정보는 사용자의 기기에만 저장됩니다.

| 항목 | 내용 |
|---|---|
| 처방 정보 | 시작일, 투약 요일·시각, 펜 수, 펜당 회차, 다음 진료일, 자유 메모 |
| 투약 기록 | 투약 일시, 주사 부위, 회차, 메모 |
| 컨디션 기록 | 투약 후 증상과 강도, 식욕, 메모 |
| 체중 | 직접 입력한 값, 또는 Apple 건강 앱에서 읽은 체중 |
| 생활 기록 (해당 기능 사용 시) | 단백질 식품 체크, 운동 기록, 수분·식이섬유·수면 체크 |
| 설정 | 알림 설정, 구매 여부 |

이 정보는 앱 밖으로 전송되지 않습니다. iCloud 동기화도 하지 않습니다.

## 3. Apple 건강 앱(HealthKit) 데이터

- 사용자가 허용한 경우에만 체중(그리고 해당 기능 사용 시 체지방률·제지방량·운동 기록)을 **읽기만** 합니다. 건강 앱에 쓰지 않습니다.
- 읽은 데이터는 기록 정리와 진료 전 리포트에만 씁니다. 광고·마케팅에 쓰지 않으며 제3자에게 제공하지 않습니다.
- 권한은 언제든 iPhone 설정 > 건강 > 데이터 접근 및 기기에서 끌 수 있습니다.

## 4. 알림

투약일·컨디션 체크·진료 알림은 기기 안에서 예약되는 로컬 알림입니다. 알림 문구에는 약 이름이나 용량을 넣지 않습니다.

## 5. 진료 전 리포트와 내보내기

리포트 PDF와 전체 기록 내보내기(JSON) 파일은 사용자가 공유를 선택할 때만 만들어지고, 어디로 보낼지는 사용자가 정합니다. 앱이 자동으로 보내지 않습니다.

## 6. 결제

구매는 Apple App Store가 처리합니다. 앱은 결제 정보를 받거나 저장하지 않으며, 구매 여부만 기기에서 확인합니다.

## 7. 제3자 제공·위탁

없습니다.

## 8. 삭제

앱의 설정 > 데이터 > 전체 삭제를 누르면 기기 안의 모든 기록과 설정이 즉시 영구 삭제됩니다. 앱을 지워도 기록이 함께 지워집니다. 운영자에게 보관된 사본은 없습니다.

## 9. 만 19세 미만

앱은 의사의 처방을 받은 만 19세 이상 성인을 위한 기록 도구입니다.
