## A. 배포 자동화 (TestFlight 자동 업로드)

지금은 매번 Mac에서 pull → Clean → Archive → 업로드. 이 과정을 GitHub Actions로 옮긴다.
- main에 앱 코드가 바뀌어 푸시되면: 테스트 통과 → Archive(Release) → App Store Connect 업로드 → TestFlight 내부 테스터에게 자동 배포
- 빌드 번호는 지금처럼 Claude가 커밋마다 올린다 (중복 거절 방지)
- 공개 저장소라 Actions 시간은 무료 (어제 확인). Archive는 macOS 15~20분
- **사람이 할 것**: App Store Connect API 키(Issuer ID·Key ID·.p8), 배포 인증서(.p12)와 암호, 프로비저닝 프로파일을 GitHub Secrets에 등록. 절차는 진행 결정 뒤 단계별로 적는다
- 끝나면 폰의 TestFlight 앱에서 업데이트만 누르면 된다. Xcode·pull 불필요

## B. 확인·정리 (먼저 치울 것)

1. **리포트 A4 넘침**: D20에서 "최근 검사" 칸(최대 6줄, 두 칸 3줄)이 들어갔는데, 물어볼 것·메모 줄 수 제한(`maxQuestionAndNoteLines` 8)에 검사 칸 높이를 반영하지 않았다. 검사 6개 + 질문 5개 + 메모 3개면 한 장을 넘길 수 있다. `fitsOnePage` 경고는 뜨지만, 검사가 있으면 메모 상한을 줄이는 쪽으로 규칙을 보강한다 (ReportRendererTests에 12주 최대 내용 + 검사 6개 케이스 추가)
2. **수분 체크 중복**: 오늘 화면 빠른 기록 줄의 "수분"과 오늘의 마디 카드 안 습관 체크 "수분"이 같은 값을 두 곳에서 보인다. 하나로 (빠른 기록 줄은 기록 동작 모음이므로 마디 카드의 수분·식이섬유·수면 중 수분만 빼거나, 빠른 기록에서 수분을 빼고 "컨디션"을 넣는 안)
3. **기록 탭 스크린샷 경로**: `history.*` 경로가 예전 종류별 보기로 바로 가게 되어 있어 새 날짜 중심 화면은 CI 스크린샷에 안 찍힌다. `history` 경로를 더해 주 달력·하루 카드를 찍는다
4. **펼침 배치 실기기 확인**: 유지 1초·2단 전환은 시뮬레이터로 못 본다. 실기기에서 박자·2단 기준(640pt)이 맞는지 확인 뒤 숫자 조정
5. **검사지 글자 읽기 실기기 확인**: 실제 검사지(병원마다 표 모양이 다름)로 몇 장 찍어 보고 못 읽는 패턴을 모은다 → C-1
6. **음식 사진 확인 실기기 확인**: Apple 분류기가 한식(찌개·구이 등)을 어떤 이름으로 내는지 모아 매핑(`FoodPhotoRules.keywords`)을 넓힌다 → C-2
7. 버전·빌드 텍스트(D22)와 오픈 베타 안내가 설정 아래 보이는지 (아직 main 미반영)

## C. 사진·글자 읽기 보강

1. **검사지 표 인식**: 지금은 "이름 뒤 첫 숫자"만. 병원 양식에 흔한 세로 두 칸(항목 열·결과 열이 멀리 떨어짐), 단위가 다음 줄, 소수점이 쉼표인 경우, 영문 약어만 있는 경우(GLU·TC·CREA)를 더한다. 별칭 목록을 사람이 보내 준 실제 검사지로 늘린다
2. **음식 분류 보정**: 분류기 이름 → 식품 매핑을 한식 중심으로 보강(두부조림·계란말이·닭갈비·삼겹살·생선구이). 못 찾았을 때 "비슷한 음식 고르기" 칩을 사진 아래 바로 보여 주기
3. **읽은 글자 미리 보기**: 검사지 사진을 넣었을 때 읽힌 줄을 접힌 목록으로 보여 주어, 왜 어떤 항목이 안 채워졌는지 알 수 있게. 저장하지 않고 화면에서만
4. **한 번에 여러 장**: 검사지가 2~3장일 때 모두 읽어 합치기 (지금은 4장까지 넣지만 한 장씩 읽음 → 순서대로 합치는 건 이미 되므로 안내 문구만)

## D. 오늘 화면 다듬기

1. **빠른 기록 줄에 오늘 상태 점**: 오늘 단백질·운동·체중을 기록했으면 버튼 아래 작은 점. 많고 적음이 아니라 "했음"만 (R23과 같은 원칙)
2. **지금 할 일 카드** (PROPOSAL_D20 A-1, 아직 안 함): 투약일 → 투약 기록 버튼, 컨디션 칸 열림 → 컨디션, 진료 임박 → 진료 탭. 지금은 카운트다운 카드와 컨디션 카드가 따로라서 "지금 뭘 하면 되는지"가 두 곳에 흩어짐
3. **알아 두기 위치**: 맨 아래 한 줄은 잘 안 보인다. 설정 > 정보에 이미 있으니 오늘 화면에서는 빼고, 처음 2주만 보이게 하는 안
4. **한눈에 카드 탭 동작**: 남은 펜 줄 → 기록 탭 펜 현황, 지난 부위 줄 → 투약 기록 시트의 바디맵. 지금은 체중 줄만 눌린다
5. **마디 카드 끼니 점**: 끼니 점을 눌러 바로 그 끼니 단백질 시트를 열기

## E. 기록 탭 다듬기

1. **월 보기**: 주 달력 위를 누르면 한 달 달력(투약일만 ●). 지난 달 투약 패턴을 한눈에
2. **하루 카드에서 바로 고치기**: 투약 줄 → 부위 고치기/취소, 컨디션 줄 → 수정, 체중 줄 → 삭제. 지금은 종류별 보기로 가야 한다
3. **그날 메모**: 하루 카드에 자유 메모 한 줄 (스키마: `HabitCheck.note` 옵셔널 추가 → SchemaV7 경량, 사람 확인)
4. **주 달력 표시 범례**: 지금 범례 글자가 너무 작다(.caption2). 처음 열 때만 보이고 이후 숨기거나 길게 눌러 보기

## F. 진료 탭 다듬기

1. **검사 항목 기억**: 지난 진료에서 넣은 항목·단위를 새 진료 기록의 기본 줄로 미리 채우기 (값만 비워서)
2. **결과지 사진 전체 화면**: 지금 핀치 확대가 단순하다. 두 손가락 확대·이동이 자연스럽게 되도록 `ScrollView` 기반 뷰어로
3. **다음 진료 알림 연결**: 진료 탭 "다음 진료"에서 알림 설정(며칠 전)을 바로 바꾸기 (지금은 설정 > 알림)
4. **진료 직후 흐름**: 진료일 당일·다음 날 오늘 화면에 "진료 기록을 남겨 둘까요" 한 줄 (마선생 말투, 하루 한 번)
5. **검사 추이 그래프 점 선택**: 체중 추이처럼 점을 눌러 날짜·값 보기

## G. 마선생

1. 말 걸기 대답 변형을 주제별 2~3개 더 (같은 주제 세 번째부터 같은 말이 돈다)
2. 표정 바뀔 때 눈 깜빡임 한 번 (동작 줄이기면 생략)
3. 설정에 "마선생 한마디: 자주 / 가끔 / 끄기" (가끔 = 하루 2번까지)
4. 기록 직후 한마디가 토스트와 겹쳐 보이는 기기가 있는지 확인 (1.6초 지연)

## H. 접근성·글자 크기

1. 최대 글자 크기에서 한눈에 세 줄(값 20pt)이 두 줄로 꺾이고 실루엣이 작아지는지 확인 → 세로 배치로 바꾸는 분기
2. 주 달력 7칸이 최대 글자에서 넘치는지 → 요일 글자를 숨기고 날짜만
3. VoiceOver로 오늘 화면을 순서대로 읽을 때 빠른 기록 줄 라벨("단백질 기록 버튼" 등) 보강
4. 팝업 자동 닫힘 6초가 VoiceOver 사용자에게 짧을 수 있음 → VoiceOver 켜져 있으면 닫을 때까지 유지

## I. 데이터 안전 (v2)

1. **iCloud 동기화 켜기**: 스키마는 처음부터 호환 규칙을 지켰다. Capability 추가(사람), `cloudKitDatabase: .private`, 처리방침에 "iCloud에 백업됩니다" 문구. 기기 교체·분실 대비의 근본 해법
2. **내보내기에 검사지 사진 포함 옵션**: 지금은 사진을 담지 않는다. zip 형식(JSON + 사진)을 두 번째 형식으로 두거나, 사진만 따로 "사진 내보내기"
3. 자동 백업 안내: 마지막 내보내기 30일 지나면 설정에 한 줄
