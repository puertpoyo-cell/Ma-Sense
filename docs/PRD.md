# PRD — 마선생 Masense

버전 1.0 · 2026-10-20 · 근거: 아이디에이션 문서(2026-10-13)

## 1. 한 줄 정의

주 1회 GLP-1 주사 루틴을 판단하지 않고 기록하고, 단백질·근력운동으로 근육을 지키는 감량 습관까지 챙겨 주며, 진료 전 리포트 한 장으로 정리해 주는 온디바이스 iOS 앱.

핵심 메시지: **처방은 의사가, 기록은 마선생이.**

## 2. 배경과 문제

- 주 1회 투약이라 "이번 주 맞았나", "어느 부위에 맞았나", "펜이 몇 회 남았나"를 잊기 쉽다.
- 진료는 4~8주 간격인데, 그 사이의 부작용·체중·식사 변화를 의사에게 말로 설명하기 어렵다.
- 감량 중 근육 손실이 화두이지만, 단백질·근력운동을 꾸준히 챙기게 하는 도구가 없다.
- 기존 다이어트 앱은 칼로리·목표 체중·경쟁 구조라서 GLP-1 사용자의 "덜 먹히는" 상황과 맞지 않고, 오남용을 부추길 위험이 있다.

## 3. 사용자

### 주 사용자
- 만 19세 이상, 의사 처방으로 주 1회 GLP-1 주사를 맞는 성인
- iPhone 사용, Apple Health 또는 Apple Watch로 체중·운동을 이미 기록하는 비율이 높음
- 원하는 것: 잊지 않기, 기록 부담 없음, 진료 때 할 말 정리

### 보조 독자
- 담당 의사: 리포트 PDF를 3초 안에 훑고 투약 이행·부작용·체중 추이를 파악

### 비사용자 (의도적으로 배제)
- 처방 없이 감량 목적으로 약을 구하려는 사람
- 미성년자

## 4. 제품 원칙

1. **판단하지 않는다.** 칭찬·질책·점수·랭킹 없음. 모든 입력의 결과는 "기록했습니다."
2. **의료 결정은 앱 밖에 있다.** 용량, 증량, 식단 처방, 운동 처방을 하지 않는다. 안내는 "의사와 상의하세요"로 끝난다.
3. **짧은 의식, 확실한 결과물.** 매주 3번의 짧은 탭(알림 → 기록 → 컨디션)이 쌓여 리포트 한 장이 된다.
4. **데이터는 기기 안에.** 서버 없음. 건강 데이터는 외부로 나가지 않는다.
5. **감량의 질.** 체중 숫자가 아니라 단백질·근력운동 이행으로 "잘 빼고 있는가"를 보여 준다.

## 5. 범위

### 5.1 M1 — MVP (투약 루프)

| ID | 기능 | 설명 | 우선순위 |
|---|---|---|---|
| F1 | 투약 기록 | 날짜·시각·부위·용량 메모(자유 텍스트)·펜 회차 기록 | P0 |
| F2 | 투약 알림 | 설정한 요일·시각에 로컬 알림. 미기록 시 당일 저녁 1회 리마인드 | P0 |
| F3 | 카운트다운 | 홈 화면에 다음 투약까지 D-n, 시간 표시 | P0 |
| F4 | 바디맵 | 복부(좌/우 상·하), 허벅지(좌/우), 상완(좌/우) 8구역. 최근 사용 부위 표시, 추천 없음 | P0 |
| F5 | 48시간 컨디션 체크 | 투약 후 24h·48h에 알림. 구역·구토·변비·설사·식욕저하·피로·주사부위반응 등 체크 + 강도 0~3 | P0 |
| F6 | Apple Health 체중 연동 | HealthKit 체중 읽기, 앱 내 수동 입력도 가능 (HealthKit에 쓰기는 v1.1) | P0 |
| F7 | 처방 관리 | 펜 수, 펜당 회차, 현재 회차, 다음 진료일. 처방 소진 전 진료 예약 리마인더 | P0 |
| F8 | 진료 전 리포트 PDF | 투약 이력, 누락, 부작용 빈도, 체중 추이를 A4 한 장으로 | P0 |
| F9 | 온보딩 | 역할 고지("처방은 의사, 기록은 마선생"), 만 19세 이상 확인, 투약 요일·시각 설정, HealthKit 권한 | P0 |

### 5.2 M2 — 확장 (근육 지키는 감량)

| ID | 기능 | 설명 | 우선순위 |
|---|---|---|---|
| F10 | 단백질 채우기 | 끼니별 단백질 식품 원탭 체크. 하루 목표(g)는 사용자/의료진 입력. 기본 안내 범위 1.2~1.6 g/kg 출처와 함께 표시 | P1 |
| F11 | 식욕 저하일 모드 | 컨디션 체크에 구역·식욕저하가 있으면 "작게 자주" 선택지(셰이크 등) 노출 | P1 |
| F12 | 근력운동 마디 | 주 2~3회 전신 근력 기록. 맨몸 15~20분 루틴 예시 제공(일반 건강정보) | P1 |
| F13 | 컨디션 연동 | 컨디션이 안 좋은 날은 걷기·스트레칭 옵션 상단, "쉬는 날도 기록" | P1 |
| F14 | 기본 습관 | 수분·식이섬유·수면 가벼운 체크. 점수화 없음 | P2 |
| F15 | 감량 속도 안내 | 2주 연속 주당 감소가 1 kg를 넘으면 일반 권장(주 0.5~1 kg, CDC)과 "의사와 상의하세요" 안내 | P1 |
| F16 | 리포트 확장 | 단백질 달성일 수, 근력운동 횟수, 골격근량 추이(입력 시) | P1 |
| F17 | HealthKit 운동·제지방량 읽기 | Apple Watch 운동 기록을 근력운동 마디로 자동 인식, 제지방량 추이 | P2 |
| F18 | 리포트·위젯 테마 구매 | StoreKit 2 비소모성 1종 | P1 |

## 6. 하지 않을 것 (고정)

| 항목 | 이유 |
|---|---|
| 용량 추천, 증량 시점 제안 | 전문가용 디지털의료기기 영역 (식약처 2026-09-30 가이드라인) |
| 칼로리 목표, 목표 체중 설정 | 급감량 유도, 오남용 맥락 |
| 랭킹, 공유 경쟁, 스트릭·게임형 보상 | 판단하지 않는다는 원칙 위반 |
| 커뮤니티 | 나눠 맞기·약 거래 통로 가능성 |
| 전문의약품 상표 사용 | 광고 규제, 상표권 |
| 끼니 거르기·급감량을 성공처럼 보이게 하는 표현 | 건강한 감량 원칙 위반 |

## 7. 핵심 사용자 여정

```
온보딩 → 투약 요일 설정
   ↓
[매주 반복]
알림(투약일) → 투약 기록(부위·회차) → 24h/48h 컨디션 체크
   ↓ (M2) 끼니마다 단백질 체크, 주 2~3회 근력운동 기록
   ↓
진료 전날 알림 → 리포트 PDF 생성 → 공유/인쇄
   ↓
진료 후 새 처방 입력 → 다음 마디
```

## 8. 성공 지표 (베타)

| 지표 | 목표 | 측정 |
|---|---|---|
| 투약 기록률 | 예정 투약 중 90% 이상 기록 | 로컬 집계, 설정 화면에서 사용자 본인만 확인 |
| 컨디션 체크 응답률 | 투약 건의 70% 이상 | 동일 |
| 리포트 생성 | 베타 테스터의 50%가 첫 진료 전 리포트 1회 이상 생성 | 테스터 설문 |
| 정성 | "의사에게 보여 줬다" 사례 수집 | TestFlight 피드백 |

분석 SDK는 넣지 않는다. 지표는 기기 내 집계와 테스터 설문으로만 본다.

## 9. 비기능 요구사항

- iOS 17 이상, iPhone 전용 (iPad는 호환 모드)
- 네트워크 없이 모든 기능 동작
- 앱 실행 → 홈 표시 1초 이내
- 리포트 PDF 생성 3초 이내 (12주 데이터 기준)
- 접근성: Dynamic Type, VoiceOver 레이블, 색만으로 의미 전달 금지
- 한국어 우선, 영어 키 준비

## 10. 수익 모델

- 무료: 기록, 알림, 컨디션 체크, 바디맵, 습관 전부
- 유료(평생 구매 1종): 리포트 PDF 내보내기, 위젯·리포트 테마
- 구독 없음. 건강 앱은 일회성 결제가 신뢰를 얻기 쉽다는 판단
