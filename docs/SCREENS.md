# SCREENS — 화면 사양

내비게이션은 탭 3개 + 모달 시트. 모든 화면은 `DESIGN_SYSTEM.md`의 Midnight 배경 + Frost 카드를 따릅니다.

## 내비게이션 구조

```
TabView
 ├─ 오늘 (TodayView)            house
 ├─ 기록 (HistoryView)          calendar
 └─ 리포트 (ReportView)         doc.text
Settings는 오늘 탭 우상단 gear → NavigationStack push

시트 (전역)
 ├─ DoseLogSheet        투약 기록
 ├─ ConditionCheckSheet 컨디션 체크
 ├─ ProteinSheet        단백질 채우기 (M2)
 ├─ StrengthSheet       운동 기록 (M2)
 ├─ WeightEntrySheet    체중 수동 입력
 └─ PrescriptionSheet   처방 입력/수정
```

## 시작 전환 화면 (SplashView)

앱을 새로 열 때마다 1초: midnight 바탕 + M 마크 + "마선생" + "처방은 의사가, 기록은 마선생이." → 흐려지며 온보딩 또는 홈. 백그라운드에서 돌아올 때는 없음 (DESIGN_SYSTEM.md 6)

## 알림에서 들어오기 (D6, R4-1)

투약 알림의 "기록하기"나 본문을 누르면 오늘 탭으로 가서 투약 기록 시트(S2)를 연다. "1시간 뒤 다시 알림"은 앱을 열지 않는다. 컨디션 알림은 지금 열린 컨디션 체크(S3)를 연다. 위젯·Live Activity의 `masense://log-dose`도 같은 길로 들어온다.

## 위젯 (D6, NextDoseWidget)

홈 화면(작게·중간)과 잠금 화면(사각·원·한 줄). 앱이 App Group에 써 둔 요약만 읽는다 (DATA_MODEL.md 저장 위치). 사실만, 약 이름·용량·"주사" 단어 없음 (COMPLIANCE.md 3.3).

- 작게: 위 "다음 투약" / 가운데 큰 `D-2` / 아래 "10. 22. (목) 오후 8:00"
  - 예정일 당일은 `D-Day`, 예정 시각이 지나고 기록이 없으면 "예정일이 지났습니다" + `D+n`(당일이면 `D-Day`)
  - 이번 마디를 기록했으면 다음 마디 구간(예정 이틀 전) 전까지 "이번 마디 기록 완료 · 다음 투약"
  - 처방 없음 "처방을 입력하면 마디가 시작됩니다", 소진·마지막 회차 뒤 "새 처방을 입력하세요" (큰 숫자 없음)
- 중간: 작게 + 오른쪽 "마지막 부위"(부위 기록 없음이면 그 문구)·날짜, "남은 회차 n회"
- 잠금 화면: 사각 = 문구·`D-n`·요일 시각, 원 = `D-n`, 한 줄 = "다음 투약 D-n"
- 누르기: 예정일 당일이거나 지났으면 `masense://log-dose`(오늘 탭 + 투약 기록), 그 밖에는 앱만 연다
- 다시 그리기: 앞으로 8일의 자정, 다음 마디 구간 시작, 예정 시각에 항목을 두고, 기록이 바뀌면 앱이 바로 다시 그리게 한다

## Live Activity (D6, DoseDayLiveActivity)

서버가 없어 푸시로 시작할 수 없다. **투약일에 앱을 열면** 시작하고, 투약을 기록하면 끝난다 (`LiveActivityRules`, `refreshReminders`). 오늘이 예정일이고 이번 마디를 아직 기록하지 않았을 때만. 지난 예정일(D+1 이후)에는 띄우지 않는다. 사용자가 설정에서 Live Activity를 끄면 시작하지 않는다.

- 잠금화면: "오늘 투약일" / 예정 시각까지 줄어드는 시간(예정 시각이 지나면 "예정 시각이 지났습니다") / "예정 오후 8:00", 오른쪽 "눌러서 기록"
- Dynamic Island: 작게 = 달력 아이콘 + 예정 시각, 펼치면 위 "오늘 투약일"·예정 시각, 아래 남은 시간
- 누르면 `masense://log-dose`. 예정 시각에 한 번 다시 그려 문구를 바꾸고, 그날이 끝나면 흐리게(stale)

## S0. 온보딩 (첫 실행)

4페이지 수평 페이징. 건너뛰기 없음.

| 페이지 | 내용 | 완료 조건 |
|---|---|---|
| 0-1 역할 고지 | 큰 타이포 "처방은 의사가, 기록은 마선생이." + 3줄 설명(판단하지 않음, 의료 조언 없음, 기기 안 저장) | "알겠습니다" 탭 → `hasAcceptedRoleNotice` |
| 0-2 연령 확인 | "이 앱은 의사의 처방을 받은 만 19세 이상 성인을 위한 기록 도구입니다" | 체크박스 + "확인" → `hasConfirmedAdult` |
| 0-3 처방 설정 | `PrescriptionSheet` 인라인 (투약 요일·시각, 펜 수, 펜당 회차, 시작일, 다음 진료일 선택) | 저장 |
| 0-4 연동·알림 | HealthKit 권한 요청 버튼(선택), 알림 권한 요청 버튼 | "시작" (권한 거부해도 통과) |

## S1. 오늘 (TodayView) — 홈

위에서 아래로 카드 스택. 각 카드는 Frost 카드.

### 1-1 카운트다운 카드 (항상) — `CountdownHero` (DESIGN_SYSTEM.md 5.2)
- 도면 셀: 좌측 메인 셀 + 우측 보조 셀 위·아래 2분할, 아래 행에 버튼
- 좌측 메인 셀 상태별 (R2):
  - `.due`, 24시간 이상 남음: "다음 투약" / `D-n` / "다음 투약까지"
  - `.due`, 24시간 미만: `D-Day` / "다음 투약까지" / `18시간 42분` 남음, 버튼 "투약 기록"
  - `.overdue`: `D+n` (예정일 당일이면 `D-Day`) / "예정일이 지났습니다", 버튼 "투약 기록"
  - `.done`: "기록 완료" + 다음 마디 `D-n`
  - 처방 소진: "새 처방을 입력하세요", 버튼 "처방 입력" → PrescriptionSheet
- 우측 보조 셀: 위 "예정 시간" 목요일 20:00, 아래 "회차" `7 / 12`
- `.due`인데 이미 그 마디 구간 안(예정일 이틀 전부터, R1)이면 보조 버튼 "투약 기록"(GhostButton). 미리 맞은 경우의 입력 경로 (2026-10-21 확정)

### 1-1a 지난 투약 안내 카드 (D6, R3-1)
- 처방 시작일 이후 첫 기록 전에 비어 있는 주가 있고 남은 회차가 있을 때만, 카운트다운 카드 바로 아래
- "지난 투약 기록" / "처방 시작일 이후 첫 기록 전에 기록이 없는 주가 n번 있습니다. 이 앱을 쓰기 전에 투약했다면 한꺼번에 기록할 수 있습니다." / 버튼 "한꺼번에 기록"(→ S2-1), "닫기"
- "닫기"는 그 처방에 대해 다시 띄우지 않는다 (기기 화면 상태, UserDefaults `backfill.dismissedPrescription`). 기록 탭 버튼은 남는다

### 1-1b 남은 펜 카드 (D7, R13-1)
- 처방이 있을 때 항상. 컨디션 카드 아래
- 펜 그림: 펜 하나 = 둥근 막대, 칸 하나 = 회차. 남은 회차는 채우고 쓴 회차는 테두리만, 아래 "2/4". 주사기 모양 없음
- "펜 4개 중 2개 남음" / "남은 회차 6회 · 소진 예상 12. 5." / 처방 메모가 있으면 "처방 메모 · {적은 그대로}"
- 약 이름·용량 수치 없음 (COMPLIANCE.md 2.1). 설정 > 처방에도 같은 펜 그림

### 1-2 컨디션 체크 카드 (열린 창이 있을 때만, R5)
- "투약 후 24시간 / 48시간" 라벨, 버튼 "기록"
- 창이 둘 다 열려 있으면 h24 먼저

### 1-3 체중 카드
- 최근 체중과 측정일, 8주 스파크라인(주 평균, R7)
- 설정에 키가 있으면 체중 아래 "BMI 27.1" (R14, 숫자만, 구간 이름 없음)
- HealthKit 미연동 시 "Apple Health 연동" 또는 "직접 입력"
- M2: `paceNotice`가 있으면 카드 하단에 한 줄 안내 (R8). 색 강조 없음

### 1-4 오늘의 마디 카드 (M2)

- 운동: 이번 주 근력 n회, 가벼운 활동 n회. 버튼 "기록"
- 식욕 저하일(R10)이면 단백질 영역 상단에 "작게 자주" 칩 4개

### 1-5 진료 카드 (nextClinicDate 7일 이내)
- "10/28 진료", 아직 묻지 않은 것이 있으면 아래 "물어볼 것 n개" (D6)
- 버튼 "진료 때 물어볼 것" → S5-1, "리포트 준비" → 리포트 탭

### 빈 상태

## S2. 투약 기록 (DoseLogSheet)

- 맨 위 "지난 투약" 세 줄: 제목 / 부위 / "10월 15일 (목) · 7일 전" (오늘이면 "오늘"). 기록이 없으면 숨김. 사실만, 다음 부위 제안 없음 (R6 `lastDoseNote`)
- 날짜·시각 피커 (기본 now, 과거 선택 가능 — R3 누락 해제)
- 바디맵 (BodyMapView): 정면 실루엣 위 8구역. 쓴 적 있는 구역마다 마지막 사용일, 최근 4회는 농도 (R6). 아래에 "부위별 마지막 사용" 표. 탭으로 선택. 추천 표시 없음. 이전 처방의 기록도 함께 본다 (부위는 몸 기준)
- 회차: 자동 계산 "n회차 (펜 m의 k번째)", 수정 가능
- 메모 (선택)
- 저장 → 카운트다운 카드가 `.done`으로 전환, 알림 재계산 (R4)
- 완료 토스트: "기록했습니다." 그 외 문구 없음

## S2-1. 지난 투약 한꺼번에 기록 (BackfillSheet, D6)

- 진입: 오늘 1-1a 카드, 기록 탭 투약 목록 위 "지난 투약 한꺼번에 기록"(누락 2개 이상)
- 맨 위 안내: "처방 시작일(9월 24일) 이후 기록이 없는 주입니다. 이 앱을 쓰기 전에 투약한 주만 켜 두세요. 각 주의 예정 일시로 기록합니다."
- 목록 "기록 없는 주 n개": 행마다 날짜 토글, 켠 행에는 부위 메뉴(기본 "부위 기록 없음" + 8부위)
- 하단: "부위가 기억나지 않으면 부위 기록 없음으로 두세요. 기록 탭에서 나중에 고칠 수 있습니다." 주가 남은 회차보다 많으면 "남은 회차 n회까지 기록할 수 있습니다." (그 이상은 켜지지 않음), 뒤 기록 회차가 밀리면 "뒤에 있는 기록 n개의 회차도 함께 바뀝니다."
- 저장 버튼 "n회 기록" → 알림 재계산, "기록했습니다." 토스트

## S3. 컨디션 체크 (ConditionCheckSheet)

- 상단: "투약 후 24시간" / "48시간"
- 증상 10개 그리드, 각 칩 탭 → 0~3 세그먼트 표시
- 식욕: 평소 / 줄었음 / 많이 줄었음
- 메모
- 심각도 3이 하나라도 있으면 하단 고정: "증상이 심하면 의사와 상담하세요." (링크·전화 없음)
- 저장 → "기록했습니다."

## S4. 기록 (HistoryView)

- 상단 세그먼트: 투약 / 컨디션 / 체중 / 습관(M2)
- 투약: 월별 리스트. 행 = 날짜, 부위 아이콘, 회차, 메모 유무. 누락 마디는 회색 점선 행 "기록 없음" (R3). 처방이 바뀐 지점에 구분 행 "처방 변경 · {doseLabel}" (R13). 스와이프 → 취소(`isCancelled`)
  - 누락 행을 탭하면 그 예정일로 DoseLogSheet를 열어 과거 기록을 더한다 (현재 처방의 마디만). 취소한 기록은 취소선 + "취소됨"으로 남고 스와이프로 되돌릴 수 있다
  - 보관된 처방은 다음 처방 시작 전까지의 마디만 본다
  - 스와이프 버튼은 빨강 금지 원칙에 따라 중립색
  - 부위 기록 없음(D6)은 부위 자리에 "부위 기록 없음 · 눌러서 고치기". 탭하면 "부위 고치기" 시트(바디맵만)에서 부위를 고른다
  - 누락이 2개 이상이고 남은 회차가 있으면 목록 위에 "지난 투약 한꺼번에 기록" (S2-1)
- 컨디션: 투약별 그룹, 24h/48h 요약 (증상 수, 최대 강도). 창이 다 닫힌 뒤에 만든 기록(지난 투약 한꺼번에 입력 등)은 체크가 없으면 그룹을 만들지 않는다 (R3-1)
- 체중: 주 평균 라인 차트 (12주, 투약일 4pt 눈금), 아래 원 샘플 리스트(수치는 `DimensionValue`, 키가 있으면 아래에 "BMI 27.1"). "+" → WeightEntrySheet
- 습관(M2): 캘린더 그리드(`BlueprintGridLines` 7칸 도면 격자). 단백질 채운 날·근력운동 한 날 점 표시. 점수·연속일 수 없음

## S5. 리포트 (ReportView)

- 맨 위 "진료 때 물어볼 것" 카드 (D6): 아직 묻지 않은 것 앞 3개(2줄까지)와 "외 n개", 없으면 "진료 때 물어볼 것을 적어 두면 리포트에 함께 실립니다." 버튼 "물어볼 것 적기" → S5-1
- 기간 선택: 직전 진료 이후 / 4주 / 8주 / 12주 (R12)
- 미리보기: `REPORT_SPEC.md` 레이아웃을 SwiftUI로 렌더 (PDF와 동일 뷰)
- 버튼: "PDF로 내보내기" → 유료 미구매 시 구매 시트, 구매 시 `ShareLink`
- 하단 문구: "이 리포트는 사용자가 직접 기록한 내용을 정리한 것이며 의학적 판단을 포함하지 않습니다."

### S5-1. 진료 때 물어볼 것 (ClinicQuestionsSheet, D6, R15)
- 맨 위 한 줄 입력 "물어볼 것을 한 줄로 적으세요" + "추가" (키보드 완료로도 추가, 입력칸은 계속 열림)
- 하단 안내: "아직 묻지 않은 것은 진료 전 리포트에 함께 실립니다(최대 5개). 진료에서 물어봤으면 눌러서 표시하세요."
- "아직 묻지 않은 것 n개": 적은 순. 빈 원 + 문장. 누르면 물어봄으로 옮긴다
- "물어본 것": 최근에 물어본 순. 채운 원 + 흐린 문장 + "10/23 물어봄". 누르면 되돌린다
- 스와이프 "지우기"(중립색). 앱은 질문을 분류·답·제안하지 않는다

| 리포트 | 테마 (구매 후), 기본 기간 (자동 / 직전 진료 이후 / 4·8·12주, 구매와 무관) |

### S6-1. 기록 가져오기 (ImportSheet)

파일 선택(`fileImporter`, `.masense.json`·`.json`) → 형식·버전 확인(실패하면 알림: "마선생 내보내기 파일이 아닙니다." / "앱을 업데이트한 뒤 가져오세요.") → 시트.

- 파일에 담긴 기록: 내보낸 날짜, 종류별 건수 (비어 있는 종류는 숨김)
- 가져오는 방식: "현재 기록을 모두 지우고 교체"(기본) / "기존 기록에 추가". 아래에 방식별 안내 한 줄
- 오른쪽 위 "가져오기" → 확인 알림(2단계): 교체 "현재 기록을 지우고 파일의 기록으로 바꿀까요?" / 추가 "파일의 기록을 더할까요?"
- 결과(같은 시트): "기록했습니다." + 종류별 "n건 · 제외 m건" (둘 다 0이면 숨김, 화면 문구는 R10 금지어를 피해 "제외"), 제외 이유 한 줄, 건강 앱 기록 건수 안내. 성공 애니메이션 없음. "완료"로 닫음
- 저장 뒤 알림 전부 재등록, 건강 앱 연동 중이면 다시 읽기

## S7. 단백질 채우기 (ProteinSheet, M2)

- 끼니 선택 세그먼트
- 식품 칩 그리드 (12종, R9 표). 탭 → 수량 스테퍼 (기본 1)
- 식욕 저하일이면 "작게 자주" 칩이 상단 별도 행
- 하단 합계 "대략 n g". 목표 있으면 "n / 목표 g"
- 저장 → "기록했습니다."

## S8. 운동 기록 (StrengthSheet, M2)

- 종류: 근력 / 걷기 / 스트레칭 / 쉬기. 저컨디션 날이면 순서 걷기 / 스트레칭 / 쉬기 / 근력 (R11)
- 시간 (분), 강도
- 근력 선택 시 접힌 섹션 "맨몸 15~20분 예시" (일반 건강정보, COMPLIANCE 문구 가이드 준수)
- 저장 → "기록했습니다."

## S9. 처방 입력 (PrescriptionSheet)

- 시작일, 투약 요일, 시각, 펜 수, 펜당 회차(기본 4), 다음 진료일(선택), 메모(`doseLabel`, 자유 입력, 플레이스홀더 "메모")
- 투약 간격 선택 UI는 없음 — 주 1회 고정
- "용량"이라는 단어를 레이블에 쓰지 않는다. 메모 필드일 뿐
- 새 처방 시작 시 이전 처방은 `endDate` 설정 + `isActive = false` (R13). 이전 처방은 삭제되지 않고 이력으로 남음

## 공통 상태

- 로딩: 없음 (온디바이스라 즉시)
- 오류: HealthKit 거부 → 카드 내 인라인 안내, 알림 거부 → 설정 안내
- 빈 리스트: 한 줄 문구만, 일러스트 없음

## 접근성

- 바디맵 구역마다 `accessibilityLabel` ("복부 왼쪽 위, 10월 9일 사용")
- 색만으로 상태 구분 금지 — 텍스트 또는 아이콘 병행
- Dynamic Type XXL까지 레이아웃 깨짐 없음
  - 예외: 기록 탭 습관 캘린더(달 이동 줄, 7칸 격자, 범례)는 글자 크기 상한 `accessibility1` (그 이상에서는 날짜 숫자가 두 줄로 쪼개진다). 날짜·기록은 칸마다 VoiceOver 레이블로 읽는다
