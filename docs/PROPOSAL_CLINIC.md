# PROPOSAL CLINIC — 진료 탭 다음 개선 제안 (2026-11-01, 사람 승인 대기)

D28로 예약 → 결과 → 보관 흐름은 들어갔다. 쓰면서 걸릴 만한 곳을 더 줄이는 제안. 금지선(용량 해석·추천, 상표명) 닿는 항목 없음.

1. **진료 전날 "준비 한 장"** (M): 진료 알림을 누르면 물어볼 것·최근 4주 요약(투약 n회, 체중 처음→마지막, 증상 수)·리포트 열기를 한 화면에. 진료실에서 폰 하나로 끝
2. **진료 중 빠른 메모** (S): 진료 당일 진료 탭 맨 위에 "들은 것 바로 적기" 한 줄 입력. 저장하면 그날 진료 기록의 코멘트로 들어가고, 결과 적기에서 이어서 씀
3. **물어볼 것 → 답 적기** (M): 진료 결과를 적을 때 아직 묻지 않은 질문을 체크 목록으로 보이고, 체크하면 "물어봄"으로, 옆에 들은 답 한 줄
4. **받은 펜과 남은 펜 맞춰 보기** (S): 아카이브의 받은 패키지 합계 옆에 "지금 남은 펜 n개"를 같이. 숫자만, 판단 없음
5. **진료 기록 검색·필터** (M): 아카이브 위에 "펜 받음만", "검사 있음만" 칩
6. **진료 기록을 리포트에** (S): 리포트에 기간 안 진료일과 받은 패키지 수를 한 줄로 (처방 메모는 리포트에 이미 처방 전환으로 실린다)
7. **캘린더 일정 바뀜 따라가기** (L, 권한 필요): 캘린더 읽기 권한을 받아 캘린더에서 옮긴 진료 일정을 앱 예약에 반영. 권한 키가 새로 생겨 사람 확인 필요
8. **진료 기록 사진 한 장 더**: 처방전·영수증 사진도 검사지와 같은 자리에 붙일 수 있게 (글자 읽기는 검사지만)

권장 순서: 2·3·4 (한 빌드) → 1·6 → 5·8 → 7(권한 결정 뒤)
